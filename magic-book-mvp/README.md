# Волшебная книжка рисунков — MVP

Быстрый прототип по ТЗ из чата.

## Запуск
Открой `magic-book-mvp/index.html` в браузере.

## Что реализовано
- 6 экранов: меню, выбор персонажа, рисование, оживление, мини-игра, библиотека.
- Цикл: выбор → дорисовка → оживление → сбор звёзд → сохранение.
- 3 персонажа (лиса, заяц, сова).
- Палитра из 8 цветов, ластик, очистка, Undo (1 шаг).
- Мини-игра «Потерянные звёздочки» без проигрыша.
- Локальное сохранение историй (localStorage) + реплей из библиотеки.
